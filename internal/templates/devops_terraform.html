Oona Golden Path Directory Convention

When a Developer creates an onboarding ticket at /tickets/new, the Terraform Worker automatically resolves the path inside the Central IaC repository:

// Directory pattern format:

02-app-setup / {domain} / {country} / {env} / services / {service_name}

// Resolved example for PH Health Renewal Service:

02-app-setup/integration/ph/uat/services/health-renewal-svc/

├── main.tf

├── variables.tf

└── terraform.tfvars (contains DB_HOST, SSM_PARAMS)

How DevOps Approval Works:

  • Worker fetches terraform.tfvars using GitHub REST API.
  • HCL Parser extracts environment keys and secrets without executing code.
  • DevOps reviews extracted keys on /approvals page before clicking Approve.
