Production Implementation Details:
  • Zero External Dependencies: Dibuat dengan 15 baris vanilla JS menggunakan requestAnimationFrame native browser. Ringan & 60 FPS mulus.
  • HTMX Compatible: Otomatis berjalan saat load halaman pertama kali, dan jika ada event HTMX polling/swap (htmx:afterSwap).
  • Accessibility Safe: Mendukung prefers-reduced-motion (jika user menyalakan mode reduced motion di OS, angka langsung tampil tanpa animasi).
