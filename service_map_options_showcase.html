Design Concept Review Option 1: Sidebar 'Service Map' Integration

Castan Service Map — 3 Pilihan Pendekatan Visual

Membandingkan 3 arsitektur integrasi visual untuk embedding peta topologi multi-account AWS ke dalam portal Castan Service Catalog tanpa merusak layout atau menciptakan "double navigation".

Opsi A (Rekomendasi) Zen / Pro SRE

Full Immersive Canvas (Seamless Embed)

Toolbar filter & search Datadog dipadukan langsung menjadi sub-header Castan. Area peta canvas 100% mengisi viewport tanpa frame bertingkat.

Karakteristik:
  • Immersive 100%: Peta memiliki area kerja maksimal, ideal untuk inspect 30+ node.
  • Clean Unified Header: Tidak ada header ganda yang bertumpuk.
  • Palet Supabase: Warna background canvas disinkronkan ke `#0f1117` agar selaras dengan Castan.
Opsi B Catalog Inspector

Split-Screen View (Canvas + Service Drawer)

Canvas peta interaktif di sisi kiri, dengan drawer metadata detail service di sisi kanan saat salah satu node di-klik.

Karakteristik:
  • Hubungan Erat ke Catalog: Klik node langsung menampilkan repositori GitHub, owner, dan status CI.
  • Drawer Contextual: Tidak perlu meninggalkan halaman untuk melihat detail CIDR atau endpoint.
  • Area Kanvas Lebih Kecil: Area diagram berkurang 30% karena adanya panel samping.
Opsi C Multi-Perspective

Tabbed Topology Studio

Menyediakan tab view di dalam menu Service Map: Tab 1: Global Network Mesh (D3), Tab 2: Service Dependency Flow, Tab 3: Regional Shelves (ID vs PH).

Karakteristik:
  • Struktur Terorganisir: Pengguna bisa fokus pada region tertentu tanpa terdistraksi node region lain.
  • Ekspansi Masa Depan: Siap jika di masa mendatang ingin menambah tab "Kubernetes Cluster Map" atau "Kafka Event Streams".
  • Kompleksitas Navigasi: Ada dua lapis filter (tab regional di atas + filter dropdown di dalam canvas).

Rekomendasi Arsitektur: Opsi A (Full Immersive) dengan Drawer Sederhana

Pilihan paling elegan adalah **Opsi A**: menempatkan `Service Map` di sidebar utama, lalu menyatukan filter toolbar bawaan file ke dalam header Castan secara native. Saat node di-klik, drawer samping muncul (*overlay drawer* yang bisa di-dismiss).
